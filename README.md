# MineCraft-mod-ShieldUpdate-I9-23V-Rabotyagi

*Алмазный щит* для Minecraft 1.21 (Fabric)
*Java / JDK: 25*

Название проекта: Shield update

Участники Команды: Зайцев Т.В., Ромашов И.Д., Пичугин А.С.

Дисциплина:«Инструментальные средства разработки программного обеспечения»

Структура проекта:
- "src/main/java" - Содержит исходный код программы.
- "src/main/resources" - Содержит ресурсы и файлы конфигурации проекта.                                     
  Объект:Инструмент diamond_shield -- Инструмент защиты.      
- — Назначение: Инструмент diamond_shield — предназначен для защиты при зажатии ПКМ; состав проекта: src/main/java содержит исходный код программы, src/main/resources — ресурсы и файлы описания блока;        
  — Совместимость: Minecraft 1.21, загрузчик Fabric, JDK 25, Gradle Wrapper 9.8.0;         
  — Установка: подготовить совместимую игровую среду, поместить diamond_shield-1.0-SNAPSHOT.jar в каталог mods, запустить игру и убедиться, что блок доступен в творческой вкладке;        
  — Свойства блока: прочность 850;                  
  — Дополнительное поведение: при зажатии правой кнопкой мыши с предметом в руках производится анимация (пользовательский сценарий: игрок находится в мире и зажимает ПКМ с предметом в руках);              
  — Известные ограничения: поведение реализует анимацию без сохранения состояния предмета; поддержка проверена только для версии 1.21.
